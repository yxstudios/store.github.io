# 🎮 RBX Systems - Tienda de Sistemas para Roblox

![RBX Systems](https://img.shields.io/badge/RBX-Systems-blueviolet?style=for-the-badge&logo=roblox&logoColor=white)

![Supabase](https://img.shields.io/badge/Supabase-Powered-3ECF8E?style=for-the-badge&logo=supabase&logoColor=white)

Sitio web profesional para vender sistemas y scripts de Roblox. Incluye autenticación con Google/Email, carrito de compras, panel de usuario y diseño moderno con temática gamer.

## ✨ Características

### 🔐 Sistema de Autenticación
- Registro e inicio de sesión con email y contraseña
- Autenticación con Google OAuth
- Sesiones persistentes
- Protección de rutas (páginas privadas)
- Panel de usuario personalizado

### 🛒 Tienda y Carrito
- Catálogo de productos con filtros por categoría
- Búsqueda en tiempo real
- Carrito de compras persistente (localStorage)
- Control de cantidades
- Sistema de códigos promocionales
- Proceso de checkout en 3 pasos
- Múltiples métodos de pago (PayPal, Robux, Crypto)

### 👤 Panel de Usuario
- Información del perfil
- Estadísticas de compras
- Historial de actividad
- Avatar de Google

### 🎨 Diseño
- Tema oscuro profesional
- Diseño responsive (mobile-first)
- Animaciones y transiciones suaves
- Iconos de Font Awesome
- Fuentes de Google Fonts (Poppins)
- Notificaciones toast

## 🛠️ Tecnologías Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Backend:** [Supabase](https://supabase.com/) (BaaS)
- **Autenticación:** Supabase Auth (Email/Password + Google OAuth)
- **Iconos:** [Font Awesome 6](https://fontawesome.com/)
- **Fuentes:** [Google Fonts - Poppins](https://fonts.google.com/specimen/Poppins)
- **Hosting:** GitHub Pages

## 📋 Requisitos Previos

Antes de comenzar, necesitas:

1. Una cuenta en [Supabase](https://supabase.com) (gratuita)
2. Un proyecto en [Google Cloud Console](https://console.cloud.google.com) (para OAuth de Google)
3. Una cuenta de [GitHub](https://github.com) (para el hosting)
